02 Method

The pipeline.

01

Poll

The live boxscore is a CDN JSON snapshot, not a push feed — score, period and clock every twelve seconds. Polling is the correct approach here, not a compromise.

02

Recompute

Win probability comes from a model trained only on the fields available live — margin, time remaining, quarter — so training and inference can never drift apart.

03

Flag

Each run is z-scored against real runs at the same point in the game. Past two sigma it stops being momentum and starts being a heat check.
